📐 Formula Library

Important mathematical formulas with symbols, conditions and examples.

1. Euclid's Algorithm

Used to find the Greatest Common Divisor (GCD) of two integers.

Formula
a = bq + r
What do the symbols mean?
  • a = dividend
  • b = divisor
  • q = quotient
  • r = remainder
Condition

0 ≤ r < b and b ≠ 0.

Example

252 = 105 × 2 + 42

105 = 42 × 2 + 21

42 = 21 × 2 + 0

Therefore, GCD(252,105) = 21.

2. Congruence

Two integers are congruent modulo n when they leave the same remainder after division by n.

Formula
a ≡ b (mod n)
Equivalent condition
n | (a − b)
What do the symbols mean?
  • a = first integer
  • b = second integer
  • n = modulus
  • | = "divides"
Condition

n must be a positive integer and must divide the difference (a − b).

Example

17 ≡ 5 (mod 12)

Because 17 − 5 = 12 and 12 is divisible by 12.

3. Linear Congruence

A linear congruence is an equation involving modular arithmetic.

Formula
ax ≡ b (mod n)
What do the symbols mean?
  • a = coefficient of x
  • x = unknown
  • b = constant
  • n = modulus
Important condition
gcd(a,n) divides b

A solution exists only when gcd(a,n) divides b.

Example

3x ≡ 6 (mod 9)

gcd(3,9) = 3 and 3 divides 6, so solutions exist.

4. Complex Numbers

A complex number consists of a real part and an imaginary part.

Standard form
z = a + bi
What do the symbols mean?
  • z = complex number
  • a = real part
  • b = imaginary coefficient
  • i = imaginary unit
Important property
i² = −1
Modulus
|z| = √(a² + b²)
Example

For z = 3 + 4i:

|z| = √(3² + 4²) = √25 = 5

5. Polar Form of a Complex Number

Polar form represents a complex number using its modulus and argument.

Formula
z = r(cos θ + i sin θ)
What do the symbols mean?
  • z = complex number
  • r = modulus
  • θ = argument
  • i = imaginary unit
Finding r
r = √(a² + b²)
Finding θ
θ = tan⁻¹(b/a)

The correct quadrant must be considered when finding the argument.

6. De Moivre's Theorem

De Moivre's theorem is used to calculate powers and roots of complex numbers in polar form.

Formula
(cos θ + i sin θ)ⁿ = cos(nθ) + i sin(nθ)
What do the symbols mean?
  • θ = argument
  • n = integer power
  • i = imaginary unit
When is it used?

It is especially useful for calculating powers and roots of complex numbers.

Example
(cos θ + i sin θ)³ = cos(3θ) + i sin(3θ)

7. Sequences

A sequence is an ordered list of numbers.

Arithmetic Sequence
aₙ = a₁ + (n − 1)d
What do the symbols mean?
  • aₙ = nth term
  • a₁ = first term
  • n = position of the term
  • d = common difference
Convergence
lim(n→∞) aₙ = L

A sequence converges when its terms approach a finite value L.

8. Permutations

A permutation is an arrangement where order matters.

Formula
ⁿPᵣ = n! / (n − r)!
What do the symbols mean?
  • n = total number of objects
  • r = number of objects arranged
  • ! = factorial
When do we use it?

Use permutations when the order of arrangement matters.

Example
5P2 = 5! / 3! = 20

9. Combinations

A combination is a selection where order does not matter.

Formula
ⁿCᵣ = n! / [r!(n − r)!]
What do the symbols mean?
  • n = total number of objects
  • r = number selected
  • ! = factorial
When do we use it?

Use combinations when the order does not matter.

Example
5C2 = 5! / (2!3!) = 10

10. Injective Function

An injective function is also called a one-to-one function.

Condition
f(a) = f(b) ⇒ a = b
What do the symbols mean?
  • f = function
  • a, b = elements of the domain
  • f(a), f(b) = corresponding outputs
Meaning

Two different inputs cannot have the same output.

Example

f(x) = 2x is injective over the real numbers.

11. Surjective Function

A surjective function is also called an onto function.

Condition
For every y ∈ B, there exists x ∈ A such that f(x) = y.
What do the symbols mean?
  • A = domain
  • B = codomain
  • x = input
  • y = output
Meaning

Every element of the codomain must be reached.

12. Bijective Function

A function is bijective when it is both injective and surjective.

Formula / Condition
Bijective = Injective + Surjective
What does this mean?
  • No two inputs have the same output.
  • Every element of the codomain is reached.
Important

A bijective function has an inverse function.

13. Inverse Image

The inverse image of a set contains all inputs that map into that set.

Formula
f⁻¹(C) = {x ∈ A : f(x) ∈ C}
What do the symbols mean?
  • f = function
  • A = domain
  • C = subset of the codomain
  • x = input
Example

If f(x) = x² and C = {4}, then:

f⁻¹({4}) = {-2, 2}

14. Limits

A limit describes the value a function approaches as x approaches a particular value.

Formula
lim(x→a) f(x) = L
What do the symbols mean?
  • x = input variable
  • a = value x approaches
  • f(x) = function
  • L = limiting value
Condition

For a two-sided limit to exist, the left-hand and right-hand limits must be equal.

Example
lim(x→2) x² = 4

15. Continuity

A function is continuous at x = a when its value and limiting behavior agree at that point.

Three Conditions
1. f(a) exists
2. lim(x→a) f(x) exists
3. lim(x→a) f(x) = f(a)
What do the symbols mean?
  • f(a) = actual function value
  • lim(x→a)f(x) = limiting value
  • a = point being tested
When is it applicable?

All three conditions must be satisfied for the function to be continuous at x = a.

Example

Polynomial functions such as:

f(x) = x²

are continuous for every real number.
